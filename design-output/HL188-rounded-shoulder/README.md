# HL188 圆弧收肩修改版

依据用户原始 STEP 修改手柄顶部接刷颈处的造型：原平顶包胶改为圆弧风格收肩，配套修改白色硬壳支撑肩与外露白色颈口。

## 下载文件

- `HL188_rounded_hard_shell.step`：修改后的白色硬壳，1 个实体。
- `HL188_rounded_soft_overmold.step`：修改后的握柄软胶及原始按钮软胶，2 个实体。
- `HL188_rounded_hard_soft_assembly.step`：上述硬壳及软胶组合，3 个实体。
- `rounded_shoulder_sections.png`：实际 CAD 的正面与侧面剖面轮廓，青色为软胶，灰色为硬壳。
- `validation.json`：检查数据、导出文件哈希与回读结果。

## 修改范围与尺寸

单位 mm，保持原坐标。顶部造型修改区为 Z139–147 mm，包胶肩部上沿 Z144.5 mm、顶部开口外半径 7.8 mm；白色外露颈口最高至 Z147 mm。保留原下部结构、点阵纹理、软胶按钮和原刷颈连接部。红色底盖和刷头不在此次输出内。

新肩部采用偏心的多截面曲面，近似四分之一椭圆收肩轮廓，衔接原有偏心刷颈；不是统一 R 值的标准圆角，也不是仅凭图片进行的精确曲面复刻。新轮廓尺寸为本次设计假设，可继续按指定高度、半径或轮廓修改。

修改后的硬壳及握柄包胶分别为有效单实体。只对本次肩部修改区域进行硬/软胶干涉检查；未将原产品全范围的原有配合问题描述为已验证。原有下部通过截取保留，质量积分会受曲面参数化影响，数值差异及 STEP 回读结果见 validation.json。

这是供审阅的结构外形修改稿，尚未完成肩部料厚、拔模、缩水、密封、材料结合与模具可行性校核，不作为开模放行文件。

## 打开方式

下载 STEP 后用 NX、SolidWorks、Creo 或 FreeCAD 打开；模型位于原始 X 约 462 mm 附近，请使用“适合窗口 / Fit All”。GitHub 文件页点击“Download raw file / 下载原始文件”。

## 体积计算说明

软胶建模 BREP 的默认体积积分约 5419.868 mm³，STEP 回读默认积分约 5452.842 mm³（差约 0.608%）；不同积分设置也给出不同结果。该质量积分比较未通过，不能据此计算已验证的用胶量或重量。已另行检查修改肩部的几何差集为零，并核对原握柄多个高度的截面；完整记录见 `validation.json`。本版用于外形审阅，不能把这些检查当作开模或质量预测放行。

下部软胶的 Z97.3、113.3、131.3、138.5 mm 四个截面做了双向轮廓抽样，检查阈值为 0.01 mm，最大抽样偏差约 0.008957 mm。此结果仅覆盖所测截面，不是全表面公差保证。
